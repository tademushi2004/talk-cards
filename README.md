# トークテーマカード

初対面どうしの飲み会などで、会話のきっかけになる質問を「カードを引く」感覚で出せるWebアプリです。スマートフォンでの利用を想定していますが、PCでも使えます。

**▶ [アプリを開く](https://tademushi2004.github.io/talk-cards/)**

## 特徴
- **カードを引く操作**: 山札を上にスワイプして引き、タップでめくります。めくったカードは、右へスワイプで「話した」、左へで「パス」にします。
- **めくる前に段階が分かる**: 裏面の色・模様・記号が、質問の段階（○ 軽め／△ 中間／◇ 深め）に対応します。色だけに頼らないので、色の見分けが難しい人でも区別できます。
- **場に合わせたフィルター**: 死・家族・つらい記憶などに触れる「重めの質問」を除くスイッチ（初期はON）と、段階・出典での絞り込みがあります。
- **作業型のカード**: 「お互いの長所を言い合う」など、答えるだけでなく何かをするカードには、やり方の説明が付きます。
- **同じ質問は1周するまで出ません**。山札の厚みが残り枚数を表し、1周するとシャッフルされます。
- **今夜の記録**: 話したカードとパスしたカードを、あとで一覧できます。
- サーバーもアカウントも不要です。設定と記録は、お使いのブラウザの中だけに保存されます。

## 使い方
1. 山札を**上にスワイプ**（またはタップ）して1枚引きます。
2. **タップ**してめくり、質問を隣の人に投げかけます。
3. 話し終えたら**右へスワイプ**（話した）、気が乗らなければ**左へスワイプ**（パス）します。下のボタンでも操作できます。
4. 間違えたら、左下の「戻す」で取り消せます。
5. 右上の「設定」で、フィルターを変更できます。

PCではキーボードでも操作できます。

| キー | 動作 |
| --- | --- |
| ↑ / スペース | 引く・めくる |
| → | 話した |
| ← | パス |
| Z | 戻す |

## 収録している質問（全44枚）
| 出典 | 枚数 | 内容 |
| --- | --- | --- |
| 36の質問 | 36 | Aron et al. (1997) の付録の質問を、英語原文から独自に日本語訳したもの。段階は原典の Set I・II・III（各12問）に対応します。 |
| ディープトーク定番 | 8 | 『最強のコミュ力の作り方』で、ディープトーク研究で使われた定番の質問として紹介されているものを、言い換えて収録したもの。 |

各カードの下部に、出典を表示します。

- 質問の効果を保証するものではありません。話したくない質問は、遠慮なくパスしてください。
- 飲み会向けに、一部の作業型カードの説明（時間の目安や「隣の人に」など）を補足しています。原典そのままではありません。

### 参考文献
- Aron, A., Melinat, E., Aron, E. N., Vallone, R. D., & Bator, R. J. (1997). The experimental generation of interpersonal closeness: A procedure and some preliminary findings. *Personality and Social Psychology Bulletin*, 23(4), 363–377.

## ローカルで動かす
ビルド不要で、外部ライブラリも使っていません。リポジトリをクローンして、`index.html` をブラウザで開くだけです。

```sh
git clone https://github.com/tademushi2004/talk-cards.git
cd talk-cards
# index.html をブラウザで開く
```

質問データを JSON ではなく JavaScript ファイル（`questions.js`）にしているのは、`index.html` を直接開いたとき（`file://`）でも読み込めるようにするためです。

### テスト
質問データ・フィルター・山札・スワイプ判定のロジックを、Node.js でテストできます。

```sh
node tests/logic.test.js
```

## 質問を追加・変更する
`questions.js` の配列に、次の形式で項目を足します。項目の意味は、ファイル先頭のコメントにも書いてあります。

```js
{ id: "x01", text: "質問文", level: 1, set: null, heavy: false,
  kind: "question", hint: null, source: "suzuki", deeptalk: true }
```

| 項目 | 意味 |
| --- | --- |
| `id` | 一意な文字列 |
| `level` | 段階。1=軽め、2=中間、3=深め |
| `set` | 36の質問の Set 番号（1〜3）。それ以外は `null` |
| `heavy` | `true` なら「重めを除く」スイッチの対象 |
| `kind` | `"question"`（普通の質問）または `"task"`（作業型） |
| `hint` | 作業型の説明文。不要なら `null` |
| `source` | `"aron1997"` または `"suzuki"` |
| `deeptalk` | `true` なら「ディープトーク定番」バッジを表示 |

新しい `source` を追加する場合は、`app.js` の `VALID_SOURCES` と `sourceLabel`、`index.html` の出典の選択肢にも追記してください。
