# トークテーマカード

飲み会などで、会話のきっかけになる質問を、カードを引くように1枚ずつ引けるWebアプリです。スマートフォン向けですが、PCでも使えます。

## 使い方
1. `index.html` をブラウザで開く（ダブルクリックでOK。サーバー不要）。
2. 山札を**上にスワイプ**（またはタップ）して1枚引き、**タップしてめくる**。
3. 話し終えたら**右へスワイプで「話した」**、**左へスワイプで「パス」**。下のボタンでも操作できます。
4. 間違えたら「戻す」（↶）で取り消せます。
5. 「記録」で、その夜に話したカードを振り返れます。
6. 「設定」で、重めの質問を除く（初期はON）、段階（○軽め／△中間／◇深め）、出典を選べます。

カードの裏面の色・模様・記号で、めくる前に段階が分かります。1周するまで同じ質問は出ません。設定と記録はブラウザに保存されます。

PCではキーボードでも操作できます。↑またはスペースで引く・めくる、→で話した、←でパス、Zで戻す。

## ファイル構成
| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（カード、山札、シート、ダークモード） |
| `questions.js` | 質問データ（全44枚） |
| `gesture.js` | スワイプ・タップの判定 |
| `app.js` | 山札・状態遷移・記録・画面の制御 |
| `tests/logic.test.js` | ロジックのテスト（`node tests/logic.test.js`） |
| `docs/devlog.md` | 開発記録（経緯・設計判断・実装ログ） |

質問を追加・変更するときは、`questions.js` の配列を編集します。項目の意味はファイル先頭のコメントを参照してください。

## GitHub Pages で公開する
1. このフォルダをGitHubのリポジトリとして push する。
2. リポジトリの **Settings → Pages** を開く。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存する。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で使えます。

## 出典
- 36の質問: Aron, A., Melinat, E., Aron, E. N., Vallone, R. D., & Bator, R. J. (1997). The experimental generation of interpersonal closeness: A procedure and some preliminary findings. *Personality and Social Psychology Bulletin*, 23(4), 363–377. 付録の質問を独自に日本語訳したもので、段階は原典の Set I・II・III に対応します。
- ディープトーク定番: 『最強のコミュ力の作り方』で、ディープトーク研究で使われた定番の質問として紹介されているものを言い換えて収録しています。
